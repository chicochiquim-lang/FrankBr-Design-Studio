# Sprint 005 — Zoom Engine

## Implementado

- Ctrl + roda do mouse.
- Zoom focado no cursor.
- Botões + e −.
- Ajustar documento à tela.
- Retorno à visualização inicial de 35%.
- Percentual sincronizado na barra superior e na barra de status.
- Limites de 8,75% a 560% efetivos.
- Grid acompanhando o zoom sem dupla aplicação de escala.

## Atalhos

- Ctrl + roda: zoom no cursor.
- Ctrl + `+`: aumentar.
- Ctrl + `-`: diminuir.
- Ctrl + `0`: voltar a 35%.
- Ctrl + Shift + `0`: ajustar à tela.
