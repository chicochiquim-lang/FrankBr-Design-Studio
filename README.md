# FrankBr Design Studio

**Design sem limites para simuladores e projetos gráficos.**

Commit #0001 — fundação do monorepositório em .NET 8/WPF.

## Executar

1. Abra `FrankBr-Design-Studio.sln` no Visual Studio 2022.
2. Instale a carga **Desenvolvimento para desktop com .NET**.
3. Defina `FrankBr.App` como projeto de inicialização.
4. Pressione `F5`.

## Conteúdo inicial

- Aplicação WPF com tema escuro.
- Canvas padrão de 2048 × 2048 pixels.
- Painéis de Templates, Propriedades e Camadas.
- Barra de status com zoom, coordenadas e resolução.
- Contratos iniciais para documentos `.frankbr`, templates e plugins.
